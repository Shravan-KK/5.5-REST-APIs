# 5.5 REST APIs

A client application demonstrating a small REST API built with Node.js, express and axios.

## Description

This repository contains a minimal REST API example used for practice and learning.

## Requirements

- Node.js (v14+ recommended)
- npm

## Install

From the project root run:

```bash
npm install
```

## Run

Start the app with:

```bash
node index.js
# or, if a start script exists
npm start
```

Then open the API endpoints in your browser or use a tool like `curl` or Postman.

## Project structure

- `index.js` — application entry point
- `solution.js` — solution code used in the project
- `views/index.ejs` — template used by the app

## Tchnologies used

- Node.js
- Express
- Axios
- EJS
